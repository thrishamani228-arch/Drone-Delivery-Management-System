# Drone Delivery Management System

##  Project Overview

The **Drone Delivery Management System** is a Database Management System (DBMS) project developed using PostgreSQL. It is designed to manage drone-based delivery operations by maintaining customer information, drone details, pilot records, orders, and delivery information.

The system uses relational database concepts to organize and manage delivery-related data efficiently.

## Objectives

- Maintain customer information.
- Store and manage drone details.
- Manage customer delivery orders.
- Maintain pilot information.
- Track delivery status and ratings.
- Retrieve information using SQL queries.

##  Technologies Used

- **Database:** PostgreSQL
- **Query Language:** SQL
- **Database Concepts:** DBMS, Relational Tables, Primary Keys, Foreign Keys, Constraints, Joins, Views, Indexes, Sequences and Triggers.

##  Database Tables

The project contains five main tables:

| Table | Description |
|---|---|
| Customers | Stores customer details |
| Drones | Stores drone information and availability |
| Orders | Maintains customer orders |
| Pilots | Stores pilot details |
| Deliveries | Maintains delivery information and ratings |

## SQL Concepts Implemented

- CREATE, ALTER and DROP
- INSERT, UPDATE and DELETE
- SELECT queries
- WHERE, ORDER BY and LIMIT
- GROUP BY and HAVING
- DISTINCT and LIKE
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL JOIN
- UNION
- Views
- Indexes
- Sequences
- Triggers
- Primary Key and Foreign Key constraints

## How to Run the Project

1. Install PostgreSQL.
2. Open pgAdmin.
3. Create a new database.
4. Open the Query Tool.
5. Open the project SQL file.
6. Execute the SQL commands.
7. Run SELECT queries to view the database records.

**Note:** Review the SQL script before execution. Use PostgreSQL-compatible trigger syntax and avoid executing destructive table and data commands in the middle of the demonstration script.
